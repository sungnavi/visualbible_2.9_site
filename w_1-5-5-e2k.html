하나님의 말씀은 살았고 운동력이 있어 좌우에 날선 어떤 검보다도 예리하여 혼과 영과 및 관절과 골수를 찔러 쪼개기까지 하며 또 마음의 생각과 뜻을 감찰하나니
(히4:12)

운영체제의 언어 관련 설정이 잘못된 경우입니다. 이 문제의 해결을 위하여 다음 절차를 따라 진행해 주십시오.

Control Panel > Regional Options로 들어가셔서,

1.General 탭 > Settings for the current user > Your locale (location):을 Korean으로 지정하십시오.

2.General 탭 > Language settings for the system에서 Korea에 체크하시고, Set Default 단추를
눌러 English로 되어 있는 설정을 Korean으로 지정합니다. (이 과정에서 Korean Language Pack
이 포함된 Windows 2000 CD가 필요할 수 있습니다.)

3.Input Locales 탭 > Input language를 Korean으로 지정하시고, Set as Default 단추를 누릅니다.
