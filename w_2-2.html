하나님의 말씀은 살았고 운동력이 있어 좌우에 날선 어떤 검보다도 예리하여 혼과 영과 및 관절과 골수를 찔러 쪼개기까지 하며 또 마음의 생각과 뜻을 감찰하나니
(히4:12)

비주얼바이블의 서체와 관련된 문제가 있을 경우에 나타나는 현상입니다. 다음 순서에 따라 해결하십시오.

1. 서체가 없는 경우
내 컴퓨터를 여시고 C:\Windows\FONTS 창을 열어 주십시오. 그리고 TobestHeb, TobestGrk 등의 서체가 있는지 확인해 주시고, 없으면 Visual Bible CD의 FONT 폴더에서 서체 파일들을 C:\Windows\FONTS로 복사해 넣어 주십시오. Windows 98, ME의 경우, 간혹 복사 과정이 비정상적으로 진행되는 경우가 있는데, 이는 서체가 너무 많거나 운영체제의 서체 관련 부분에 문제가 생긴 경우입니다. 이럴 때는 서체를 200개 이하로 줄이시고, 운영체제를 다시 설치하시는 것이 좋습니다.

2. 서체는 있는데 등록이 안된 경우
C:\Windows\FONTS에 서체 파일들이 있다면, 더블클릭했을 때 다른 서체처럼 서체창이 뜨면서 글자 모양이 정상적으로 표시되는지 확인하십시오. 정상으로 확인이 되면 C:\Windows\FONTS창을 닫으시고, 비주얼 바이블을 다시 실행해 보십시오.

3. 서체가 있지만, 비정상적으로 보일 경우
C:\Windows\FONTS에 서체 파일들이 있지만, 더블클릭했을 때 글자 모양이 비정상적으로 표시된다면, 이것은 윈도우즈의 폰트가 200개 이상으로 너무 많거나, 서체 관련 레지스트리가 손상되었거나, 아니면 비디오 드라이버가 이 서체를 지원하지 않는 경우입니다. 먼저 서체가 지나치게 많지 않은지 확인하시고, 서체를 200개 이하만 남기고 나머지는 삭제해 주십시오. 윈도우즈 98, ME는 일반적으로 200-300개 이상의 서체를 설치했을 때는 문제가 발생할 수 있습니다. 재시동 하신 후, 그래도 안되면 다음 과정을 따라 레지스트리를 복원하십시오.(이 과정은 잘못하면 심각한 문제가 생길 수 있으니 전문가에게 부탁하시기를 권장드립니다.)

1. 시작->실행->regedit 입력후 확인
2. 좌측창에서 HKEY_LOCAL_MACHINE -> Software -> Microsoft -> Windows -> CurrentVersion -> Fonts키를 선택
3. 마우스 오른쪽 단추를 클릭하여 Fonts키를 삭제
4. CurrentVersion 선택후 마우스 오른쪽 단추를 클릭하여 새로 만들기 -> 키 -> Fonts라는 이름으로 만듬
5. 레지스트리 편집기 종료후 시스템 재시동

4. 비디오 드라이버가 서체를 지원하지 않는 경우
다음 세가지 방법을 시도해 보십시오.
1) 비디오카드의 제조사 홈페이지로부터 최신 드라이버를 다운받아서 설치해 보십시오.
2) 바탕화면에서 마우스 오른쪽 클릭->속성(등록정보)->설정->고급->문제 해결(성능)을 선택하여, 하드웨어 가속을 사용 안함으로 설정하고 시스템을 재시동해 보십시오.
3) 윈도우즈 업데이트 사이트에서 최신 권장 업데이터를 모두 설치하십시오.
